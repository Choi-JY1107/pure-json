# ADR-007: 전면 비주얼 리브랜딩 (pure.json 아이덴티티)

- **상태**: 완료 (2026-07-16)
- **관련**: 트래픽 확보(이탈률/체류시간/모바일 친화도), 첫인상 신뢰 강화, [[006-adsense-rejection-analysis]]

## 배경

기존 UI는 Material Design 3 기반으로 기능적이었으나, 트래픽 유입 관점에서 약점이 있었다.

- 홈(JSON Viewer) 진입 시 빈 에디터 2개가 화면을 채워 첫인상에 가치 전달이 없었다.
- 핵심 차별점("No Server, No Data Leak")이 사이드바 하단 회색 소형 텍스트에 묻혀 있었다.
- 전역적으로 대문자 초소형 텍스트를 남용해 가독성이 낮았다.
- 모바일에서 에디터가 세로 공간을 과도하게 차지했다.

## 결정

"페이지가 곧 자기 자신을 설명하는 JSON 문서다"라는 컨셉으로 개발자 감성의 독자적 아이덴티티를 도입한다.

### 디자인 토큰

- **팔레트**: 중립 검정 대신 잉크 블루블랙 베이스. 브랜드 아이리스 바이올렛(키), 에메랄드(문자열/프라이버시), 앰버(숫자), 핑크(keyword) 구문 강조 팔레트에서 파생.
- **타이포그래피**: Display `Bricolage Grotesque`, Body `Inter`, Mono `JetBrains Mono`. 모노를 라벨/키/그룹 제목/eyebrow 등 구조 요소의 1급 서체로 승격.
- **시그니처**: 홈 히어로에 제품 정보를 실제 구문 강조된 JSON 객체로 렌더링. 차별점을 `"dataLeaves": false`로 정면 표현.
- **로고**: `{ }` 브레이스 마크 + `json` 액센트 워드마크.

### 구조 변경

- `app.css` 토큰 시스템 전면 교체(라이트/다크 + 구문 토큰 + 접근성 기본값: focus-visible, reduced-motion).
- 홈 라우트에 히어로 + 10개 도구 그리드(내부 링크) 추가 → 발견성/체류시간/콘텐츠 보강.
- ToolPage 공통 컴포넌트 리스타일로 10개 도구 페이지 일괄 반영.
- 모바일 에디터 높이 축소(각 24rem).

## 카피 규칙

설명 카피에 가운뎃점(`·`)과 em-dash(`—`)를 쓰지 않는다. 여러 문장은 문장 단위로 줄바꿈한다.

## 남은 과제

- 트래픽/AdSense의 핵심 병목은 UI가 아니라 페이지당 텍스트 콘텐츠 부족(ADR-006). 리브랜딩은 이탈률/신뢰/모바일 신호를 개선하는 레버이며, 도구 페이지 본문 확충(페이지당 300~600단어)이 병행되어야 한다.
- 기존 i18n 본문에 남아있는 `—` 문자 일괄 정리는 후속 작업으로 분리.
